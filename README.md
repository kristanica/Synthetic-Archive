# Synthetic Archive

A minimalist digital art portfolio website created for a **Web Development** subject. The site presents a curated collection of pixel art under the fictional persona of **"Lain"** — all artwork displayed belongs to their respective real artists, credited on the [Disclaimer](Disc.html) page.

> **Note:** "Lain" is a fictional persona created for this project. All pixel art featured on this site is the work of real artists sourced from DeviantArt.

## Pages

| File             | Description                        |
| ---------------- | ---------------------------------- |
| `index.html`     | Landing / splash page              |
| `homepage.html`  | Main gallery & artist spotlight    |
| `STATHIS.html`   | Projects page (Stathis collection) |
| `ANIMITA.html`   | Animated works archive             |
| `WhoIsLain.html` | About / biography page             |
| `Disc.html`      | Disclaimer & artist credits        |

## Project Structure

```
Synthetic-Archive/
├── index.html          # Entry point
├── homepage.html       # Main gallery
├── STATHIS.html        # Projects
├── ANIMITA.html        # Animated archive
├── WhoIsLain.html      # About page
├── Disc.html           # Disclaimer & credits
├── styles.css          # Global styles
├── theme.js            # Light/dark theme toggle
├── Homepage_imgs/      # Images for homepage
├── WhoisLain_imgs/     # Images for about page
├── ArtistProfile/      # Artist profile images for disclaimer
├── ANIMATE/            # Assets for animated pages
├── STATICC/            # Static assets
└── imgs/               # General images
```

## Features

- Light/dark theme toggle
- Scroll-reveal animations
- Grayscale-to-color hover effect on gallery items
- Marquee text banners
- Contact form
- Fully static — no build step required

Open `index.html` in a browser, or serve locally with any static file server:

```bash
npx serve .
```
